# Library Management SQL Project

## Project Description
This project is a Library Management System created using SQL.

## Features
- Manage books
- Manage library members
- Track borrowed books
- Perform SQL queries and generate reports

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Aggregate Functions
- CASE Statement
- Subqueries
- CTE
- Window Functions
- Views

## Tools Used
- PostgreSQL
- pgAdmin 4
- GitHub
